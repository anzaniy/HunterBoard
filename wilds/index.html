QUEST BOARD

Press SELECT on any quest to see its target monsters and rewards. HRP values come from the Kiranico v1.040 database. Zenny and unique rewards are recorded separately; event quests without a published HRP value are shown as “—”. Clear times are rough community estimates, not official data.

QUEST TYPE
QUESTTYPEHUNT / TARGETHRP / CLEARZENNYQUEST REWARDTIME*

* Time is an estimate for a comfortable clear, used only to rank quests by efficiency. It is not a speedrun benchmark.

DATA SOURCES

Where the quest numbers come from.

PRIMARY

Kiranico — Wilds Database

Quest HRP values, star ranks, target monsters, and monster HP. The dataset is tagged to game version 1.040.

mhwilds.kiranico.com
PRIMARY

In-game Quest Details

Zenny, HRP, and reward items shown on the quest info screen in Wilds. This is the source of truth when a community database disagrees.

Quest Counter / posted quest screen
CROSS-CHECK

Fextralife Wiki — Quests

Quest availability, unlock conditions, event quest objectives, and event reward summaries.

monsterhunterwilds.wiki.fextralife.com
EVENTS

Official Wilds Update Notes

Event quest rotations and newly added content. Event quests change over time, so availability shown here can fall out of date.

info.monsterhunter.com
! Data last reviewed for game version 1.040. Wilds has no public API for player HR or total HRP, so this tool never reads your account — every number is entered manually.
