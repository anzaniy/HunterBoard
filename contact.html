This is the only official contact address for Hunter Board. There is no Discord server, no Patreon and no social account — if you see one claiming otherwise, it is not run by this site.

What to include

  • Wrong quest data — the quest name, what the site shows, and what you see on the in-game quest screen.
  • Outdated build — the weapon, the patch number, and which skill or armor piece changed.
  • Broken link or layout — the page address and the device or browser you are using.
  • Outlanders corrections — a link to the official announcement. Speculation and leaks are not used as sources.
  • Takedown or licensing — the exact file or page, plus the rights you represent. These are handled first.

What not to send

No account credentials, save files, personal data, or requests to host game files. Hunter Board does not accept paid placements, sponsored rankings or “guest post” link insertions.

Response time

This is a hobby project, so replies are not guaranteed and can take a while. Data corrections that are applied do not always get a reply — check the page and its version tag instead.

Rights holders: if you represent CAPCOM, TiMi Studio Group or Proxima Beta and want an asset or page changed or removed, say so directly and it will be actioned without argument.
